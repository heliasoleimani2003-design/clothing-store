# Clothing Store Console Application

Ein Java-Konsolenprojekt zur Verwaltung eines Bekleidungsgeschäfts.

## Funktionen

- Kleidungsartikel und verfügbare Größen anzeigen
- Artikel kaufen und den Bestand aktualisieren
- Bestellungen erstellen und anzeigen
- 10 % Rabatt für Mitglieder berechnen
- Benachrichtigungen für ausverkaufte Artikel abonnieren

## Verwendete Konzepte

- Objektorientierte Programmierung
- Vererbung und Polymorphismus
- Interfaces und Observer Pattern
- Listen mit ArrayList
- Eingabevalidierung und Exception Handling

## Projekt starten

1. Das Projekt herunterladen oder klonen.
2. In Eclipse als bestehendes Java-Projekt importieren.
3. Die Klasse StoreApp als Java-Anwendung ausführen.

Die Bedienung erfolgt über das Konsolenmenü.

## Hinweise

Die Daten werden nur während der Programmlaufzeit gespeichert.

Eine Benachrichtigung wird ausgelöst, wenn der Bestand eines
ausverkauften Artikels wieder erhöht wird. Dies kann im Code
über increaseStock getestet werden.
